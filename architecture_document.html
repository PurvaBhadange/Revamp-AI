1. Executive Overview

REVAMP AI is a sovereign, multi-agent Content Transformation Engine for Critical Information Infrastructure (CII) environments. It autonomously ingests raw, unstructured cyber threat intelligence and simultaneously orchestrates the generation of six distinct, fact-verified communication artifacts. The system is built on a local-first, air-gapped-ready microservices architecture ensuring zero data leakage of classified intelligence.

2. System Architecture

A. Frontend - Analyst Console

  • Framework: Next.js (React 19) + TypeScript
  • State: Zustand + TanStack Query
  • UI: Tailwind CSS, real-time tabbed workspace
  • Function: Upload, configure, review and export artifacts

B. Backend - Orchestration Layer

  • Framework: FastAPI (Python 3.11)
  • Task Queue: Celery + Redis (async broker)
  • Database: PostgreSQL (metadata and artifacts)
  • Vector Store: Local Qdrant (RAG knowledge base)

C. Sovereign AI Stack

  • LLM: Llama 3.1 8B - fully local execution
  • Embeddings: all-MiniLM-L6-v2 (384-dim)
  • Inference: Sub-20ms on CPU, no external APIs
  • Orchestrator: LangGraph (directed cyclic graph)

D. Output Artifacts

  • Executive Brief (PDF / DOCX)
  • Technical Security Advisory (PDF)
  • Presentation Deck (PPTX)
  • Social Media Campaign (LinkedIn / X)
  • Infographic (SVG)
  • Video Package (Script + MP3 + SRT)

3. Multi-Agent Transformation Pipeline

StageAgent / ComponentFunction
1. IngestionMultimodal ParserParses PDF, DOCX, TXT, images, audio, URLs into normalized chunks
2. ExtractionICO Extraction AgentBuilds a strictly typed JSON Intermediate Context Object with facts, IoCs, and MITRE ATT&CK mappings
3. RAG RetrievalQdrant + MiniLMRetrieves NIST SP 800-61 and MITRE framework context to ground generation
4. Generation SwarmExecutive / Technical / Creative AgentsParallel LangGraph nodes produce all output formats simultaneously from the ICO
5. ValidationReAct Compliance LoopCross-references each artifact against the ICO; rejects and re-routes on hallucination (max 2 retries)
6. RenderingArtifact RenderersStreams validated text to frontend; compiles into PDF, PPTX, MP4 downloads

4. Security & NCIIPC Compliance

Air-Gap Ready

Full pipeline - LLM, RAG embeddings, and artifact rendering - runs in a completely isolated, offline environment with no cloud dependencies.

Zero Data Leakage

Test datasets comply with RFC 5737 (Test Networks) and RFC 3849 (IPv6). No live production IP addresses are ever exposed in demos or testing.

Audit Traceability

Every artifact maintains a cryptographic link to its source document in PostgreSQL, providing a complete intelligence provenance trail.
